# Dice-Rolling-Game
Core Functionality:  Randomized Results: Uses cstdlib and ctime for seed-based randomization.  Special Outcome Detection: Automatically identifies "Snake Eyes" (double 1s), "Boxcars" (double 6s), and "Lucky Rolls" (sums of 7 or 11).  Interactive Loop: Features a do-while loop allowing users to roll repeatedly without restarting the program.
